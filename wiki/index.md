# DeepSeek Harness 知识图谱

## 概述

DeepSeek Harness 将模型调用、工具执行、会话记录和人机交互组合成可扩展的智能体应用。本知识库面向希望了解产品能力、定位代码和评估改动影响的读者；中文解释与可生成的数据索引共同维护。

## 证据等级

`confirmed` 表示有当前文件证据；并不表示所有部署均启用该能力，也不表示本次运行过其业务测试。包依赖由清单确认；产品关系由所属架构和功能文档确认。推测关系必须使用 `inferred`，尚待核实的关系使用 `unknown`，不得混入已经确认的调用链。

历史提交说明用于发现演进线索，当前源码决定现有行为。历史覆盖仅限本地可访问引用；范围、计数方法和限制见[覆盖报告](history/coverage.md)。

## 图的边界

图包括架构概念、用户功能、能力领域、当前 packages 与 apps 包、包内源码和测试路径、分类依赖与证据。Python SDK、原生运行时、Cordis 和文档构建通过架构入口链接；不伪装成 npm 包调用图。CodeGraph 用于进一步追踪符号和动态分派，清单依赖不能替代运行时调用关系。
