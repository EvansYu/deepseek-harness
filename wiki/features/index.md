## 功能地图

| 用户目标 | 主要能力 | 详细说明 |
|---|---|---|
| 持续对话和完成任务 | 模型、上下文、skill、压缩、持久会话、目标、计划、定时跟进 | [智能体任务](agent.md) |
| 读写代码与执行任务 | 文件、LSP、shell、PTY、后台任务、PTC、SSH、沙箱 | [编程与执行](execution.md) |
| 调研与操作环境 | 搜索、抓取、浏览器、桌面提供方 | [信息与环境操作](execution.md#网页与桌面) |
| 分工与自动化 | 子智能体、续行、workflow、Ralph、Agent Teams、MCP、hooks、webhook | [协作集成](collaboration.md) |
| 使用可视化产品 | Web、Desktop、会话导航、工具展示、文件预览、设置、批准 | [交互入口](interfaces.md) |
| 嵌入其他产品 | TypeScript/Python SDK、ACP、插件系统 | [集成入口](interfaces.md#程序化与实验入口) |
| 维护与验证 | 类型图、诊断、回放、真实 API、构建和发布 | [工程能力](engineering.md) |

## 使用边界

功能索引列的是代码库能够组合出的能力集合，不是任何单一安装的默认菜单。具体工具名称和 schema 查询[工具目录](../../docs/tool-catalog.md)，配置字段查询[配置目录](../../docs/config-catalog.md)，包之间的服务角色查询[能力服务图](../../docs/capability-seams.md)。这些已有生成文档保留各自权威性。
