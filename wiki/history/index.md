## 阶段分析

阶段是按作者月份组织的分析摘要，不表示功能只在该月存在，也不把合并日期当作功能首次实现日期。

| 阶段 | 历史主题 | 当前定位 |
|---|---|---|
| 六月：运行基础 | Cordis 与 monorepo、服务接口、agent loop、会话持久化、ACP、进程内子智能体、文件工具、Web 搜索和抓取、人机提问逐步建立 | [执行架构](../architecture/execution.md)、[编程执行](../features/execution.md) |
| 七月：交互与协作 | Hook 协议、Web/Desktop 体验、SDK、会话标题、目标、计划、存储和投影扩展；例如目标领域合并记录 PR #402 | [对话任务](../features/agent.md)、[交互入口](../features/interfaces.md) |
| 八月：持久状态与规模 | 长会话虚拟化、定时跟进、会话查询导出、投影约束、文件和图片处理、后台任务及跨平台执行持续完善；例如定时能力 PR #2109、投影约束 PR #2774 | [数据架构](../architecture/data.md)、[能力目录](../capabilities/index.md) |

这些主题来自全量记录中的说明和路径分类；选列 PR 是追溯入口，不构成对每一个历史补丁的人工正确性审计。

## 现有能力与历史区别

- 历史包含 Yarn、早期示例启动器和旧目录结构；当前构建入口和应用启动方式由根清单与[架构说明](../../docs/architecture.md)决定。
- 历史存在 Session SQLite 持久化实现，删除记录可追溯至 PR #3339。当前会话持久化索引只有 JSONL 提供方；SQLite 仍出现在非会话存储和历史全文检索中，不能混为同一后端。参见 [session](../capabilities/session.md)、[storage](../capabilities/storage.md)与[session-query](../capabilities/session-query.md)。
- 会话格式有多个历史代次和相邻迁移包；它们的存在不代表可以任意回退。以[当前格式状态](../../docs/session-format-status.md)和[数据架构](../architecture/data.md)为准。
- 实验浏览器、计算机操作、Agent Teams、语音和 WebWorker 能力需查具体包与组合；公开发布、默认启用和稳定支持是不同属性。
- 当前分支之外的 5 条提交是两条本地源码保存记录和三条合并记录。它们计入覆盖范围，不被当作当前分支已经拥有的新增功能。

## 提交分类

历史包含 7,942 条合并提交。非合并提交中，按规范化标题前缀识别到 feat 1,241 条、fix 4,184 条、test 2,023 条、docs 1,992 条、refactor 870 条、perf 127 条、build 31 条、chore 285 条、ci 246 条；另有 740 条未归类。标题分类是粗粒度观察，同一功能可能跨多个提交和 PR，不能据此推导功能数或研发投入比例。

精确统计由 [coverage.json](coverage.json)保存；每次刷新历史后需核对本页数字与主题。历史路径统计保留已删除目录，用于追踪演进，不进入当前能力图。

## 追溯方法

原始记录在本地 `history/.cache/commits.jsonl` 中，每行包含提交标识、父提交、作者时间、完整说明、变更路径和是否属于 HEAD 历史。根据功能名、路径或 PR 编号筛选，再使用 Git 查看对应补丁；最终返回当前源码和所属测试核实。原始记录未纳入版本控制，重建方式见[维护流程](../MAINTENANCE.md)。
